Documentação da API Alexis

Integre a IA brasileira de nova geração em suas aplicações. Respostas em tempo real, contexto longo e total conformidade com a LGPD.

Introdução

A API do Alexis oferece acesso programático aos modelos de linguagem da Telos Technologies. Construída para desenvolvedores brasileiros, nossa API é compatível com os principais padrões do mercado e oferece baixíssima latência em território nacional.

🌎 Base URL: https://api.cici.net.br/v1

Todos os endpoints exigem uma chave de API válida e utilizam autenticação via Bearer Token.

Autenticação

Para autenticar suas requisições, inclua sua chave de API no cabeçalho Authorization:

Authorization: Bearer sua-chave-api-aqui

Você pode gerar suas chaves de API no painel de controle após criar uma conta. Chaves possuem escopos específicos e podem ser revogadas a qualquer momento.

Chat Completions

Endpoint principal para conversação com o Alexis.

POST /chat/completions

Parâmetros

ParâmetroTipoDescrição
modelstringO modelo a ser utilizado (ex: alexis-pro)
messagesarrayLista de mensagens no formato {role, content}
temperaturefloatControle de criatividade (0.0 a 1.0, padrão 0.7)
max_tokensintNúmero máximo de tokens na resposta
streambooleanSe true, retorna respostas em streaming

Exemplo de requisição

{
  "model": "alexis-pro",
  "messages": [
    {"role": "system", "content": "Você é um assistente especializado em direito trabalhista brasileiro."},
    {"role": "user", "content": "Quais são os principais direitos do trabalhador celetista?"}
  ],
  "temperature": 0.5,
  "max_tokens": 500
}

Exemplo de resposta

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1700000000,
  "model": "alexis-pro",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "Os principais direitos do trabalhador celetista no Brasil incluem: registro em carteira, FGTS, 13º salário, férias remuneradas + 1/3, jornada de trabalho limitada a 44h semanais, horas extras com adicional mínimo de 50%, entre outros garantidos pela CLT."
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 45,
    "completion_tokens": 82,
    "total_tokens": 127
  }
}

Streaming (SSE)

Para respostas em tempo real, utilize o parâmetro stream: true. As respostas são enviadas via Server-Sent Events, token por token.

curl -X POST https://api.cici.net.br/v1/chat/completions \
  -H "Authorization: Bearer SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "alexis-flash",
    "messages": [{"role": "user", "content": "Explique o que é LGPD"}],
    "stream": true
  }'

Python SDK

Instale o pacote oficial:

pip install telos-sdk
from telos import TelosClient

client = TelosClient(api_key="sua-chave")

response = client.chat.completions.create(
    model="alexis-pro",
    messages=[
        {"role": "system", "content": "Você é um assistente útil."},
        {"role": "user", "content": "Qual a capital do Brasil?"}
    ]
)

print(response.choices[0].message.content)

Node.js SDK

npm install telos-sdk
import { Telos } from 'telos-sdk';

const client = new Telos({ apiKey: 'sua-chave' });

const response = await client.chat.completions.create({
  model: 'alexis-pro',
  messages: [
    { role: 'system', content: 'Você é um assistente útil.' },
    { role: 'user', content: 'Qual a capital do Brasil?' }
  ]
});

console.log(response.choices[0].message.content);
